# Changelog

## 1.0.0 — Chrome Web Store release

First public **1.0.0** store build.

Includes multi-site verse scanning (bible.com / YouVersion, Bible Gateway, Biblia, Blue Letter Bible, Bible Hub, Bible Study Tools), curated gazetteer + journeys, offline MapLibre + PMTiles biblical corridor, and online Esri fill outside the extract.

### Versioning note

Development builds before this store release used a **1.4.x** (and earlier) numbering line in `manifest.json`. Treat those as **pre-1.0 / 0.x-era** engineering builds — not a separate major product line. Git history of old commits is left unchanged; this release resets the public store version to **1.0.0**.
